## Decision

Links outside Semrush's index remain `UNKNOWN`, so the practical conclusion is that no credible earned-authority base is currently visible, not that a complete web-wide zero has been proved.

The first authority action should improve the existing all-ages page at:

- https://familytripwise.com/things-to-do/san-diego-with-kids.html

The existing all-ages page already routes readers and internal relevance to the San Diego hotel, stay-area, toddler, teen, and itinerary pages.

This pack does not implement the enhancement or authorize outreach. It promotes `FT-AUTH-005` / `IMP-042`, which requires explicit user approval before selection. Any first contact wave must be separately approved after the page enhancement is released.

- The [San Diego Tourism Authority member profile](https://www.sandiego.org/members/la-jolla-mom/7231) presents the publisher as a local vacation-planning and hotel specialist. This is an industry/member relationship, not a replicable cold-pitch link.

Stronger detections such as Yahoo and OpenTable require source-page inspection before being called editorial endorsements.

The conclusion is not "get 8,200 links." It is "build a real publisher identity, useful source assets, topical depth, and a small layer of relevant relationships over time."

The exact guide does not need hundreds of clean page-level links to compete. A few relevant citations sit on top of a mature domain, firsthand publisher identity, peer relationships, and broad family-travel topical coverage.

Roadmap ID: `FT-AUTH-005`

Working product name: **San Diego Family Attraction Logistics Index**

### Bounded scope

Use only the 12 activity choices already on the page. For each record, publish:

- stable attraction name and official URL;
- area and indoor/outdoor/mixed setting;
- official booking or timed-entry requirement when explicitly stated;
- official current opening/closure check link rather than copied hours;
- planning time band and cost band clearly labeled as Family Tripwise estimates;
- weather-backup role and age/height-policy check link where relevant;
- parking/transit decision prompt without claiming an exact route is easy;
- checked date, evidence class, confidence, and unresolved unknowns.

Render one compact responsive table on the existing page. Provide a client-side CSV or JSON download generated from the same embedded validated records; create no separate static data URL. Add a visible methodology/update note and changelog entry on the existing page.

Do not add safety scores, universal age fit, exact stroller practicality, sensory suitability, exact wait/drive/walk times, personally verified experience, copied review prose, or a new canonical/indexable HTML page.

### Acceptance criteria

1. Exactly the 12 already-published activity choices are represented; no destination or page expansion is hidden in the action.
2. Every externally checkable field has a direct current official source and a 2026 checked date; every estimate and `UNKNOWN` is explicit.
3. The visible table and client-side download are generated from one embedded validated record source, cannot drift, and create no separate data URL.
4. The existing page remains concise: the index replaces or consolidates overlapping decision-table material rather than stacking another long section.
5. The mobile table is usable at 320, 390, and 1440 pixels; filters, keyboard flow, and non-JavaScript content remain functional.
6. The URL, canonical, indexability, sitemap count, internal-link routes, privacy posture, and unrelated generated outputs remain unchanged.
7. Focused/full/state/SEO/source/privacy/responsive/idempotency QA and an independent read-only review pass before release.
8. Outreach remains disabled until production is verified and the user separately approves a named first wave.
